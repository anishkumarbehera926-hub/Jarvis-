JARVIS Phone Starter — Version 1

1. Open index.html in a browser or host it on HTTPS to use microphone features.
2. For phone setup, open the hosted page in Chrome and choose ⋮ > Add to Home screen / Install app.
3. Tap Start listening and allow microphone permission.
4. Say commands such as:
   - What time is it?
   - What's my routine?
   - Open Instagram
   - Open WhatsApp
   - Open YouTube
   - Open Gmail
   - Help

Important limitations:
- This is a browser-based starter, not a native Android app.
- It does not listen for a wake word in the background or while the page is closed/phone locked.
- It cannot read WhatsApp notification history, access Gmail inbox contents, silently send messages, or directly access contacts.
- WhatsApp shortcut opens a pre-filled message for you to review and send.
- Alarm creation is not implemented; use Android Clock.
- Routine is stored locally in this browser on this phone.
- Microphone speech recognition requires a supported browser and usually HTTPS.
